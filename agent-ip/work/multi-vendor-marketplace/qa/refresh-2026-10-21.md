# FreshMarket Agent IP refresh

This pass applied the Agent IP interaction, visual, authoring, assessment, and technical checks to the existing 26-module, 385-lesson FreshMarket course. The course remains in its short-lesson format. The local platform import was run after the edits, and existing learner answers were preserved.

## Shipped improvements

- Added 25 short `LearningObjectives` blocks, one near the start of each teaching module. The closing module is a presentation and evidence gate.
- Added two focused, model-backed canvases: cart-to-store-order split in 18.10 and stock holds in 24.04. Each has a written model, stated limits, reset control, labelled keyboard controls, visible outcome, and unit tests. Existing order-status and mark-packed canvases now appear in 20.09 and 20.10. The registry remains open to new canvas types and slugs.
- Added diagrams where a relationship or branch needed a picture: ownership, onboarding, product upload, catalogue filtering, cart grouping, checkout/payment, order receipts, cache, jobs, deployment, and inventory races. Replaced an ASCII diagram and duplicate step tables where a labelled flow made the mechanism clearer.
- Removed 241 repeated `RealWorldEvent` blocks, 18 repeated `MustRead` blocks, 73 repeated `InterestingRead` blocks, and 12 extra `ChapterRecap` blocks. Each remaining event and reading card appears at most once per module. Table lines in the 385 lessons fell from 6,060 to about 5,800; API contracts and comparisons that need columns remain.
- Simplified course-outline and selected concept lessons, using short sentences and concrete FreshMarket examples. Changed repetitive beginner-facing headings to plain labels.
- Fixed the 22 quiz lessons that the current quiz reader could not display. Their authored quiz questions remain intact; prose and optional cards were removed from quiz-only pages.
- Corrected store ownership to use `Store.userId` consistently through the data model, authorization, store, product, and dashboard lessons. The one-store-per-vendor rule now points to a unique `Store.userId` index and guarded create route.
- Corrected the four-week learner roadmap so required inventory and promotions work follows deployment. Updated Atlas deployment guidance against current MongoDB documentation.
- Changed the importer to reuse unchanged block IDs, preserve learner responses, archive answered blocks only when their content changes, and remove only unmatched unanswered blocks. It also preserves authored Roadmap tags during import.

## Open Agent IP gates

The platform checks pass, but the stricter Agent IP G5 depth audit still fails. Its current long-form threshold flags 381 of the 385 short lessons for prose depth and 310 for lacking a chapter-level diagram. The audit also scans `COURSE-OUTLINE.md` as a 386th chapter. This is a course-format decision: consolidating hundreds of short lessons into fewer 1,200-word chapters is a separate curriculum rewrite. The current pass did not change the Agent IP threshold or mark G5/G7 as approved.

The older industry-event cards do not carry source URLs in their component schema. They are now no longer repeated across chapters, but each retained claim still needs a source review before publication. Final instructor and delivery-lead sign-off remains a human gate.
