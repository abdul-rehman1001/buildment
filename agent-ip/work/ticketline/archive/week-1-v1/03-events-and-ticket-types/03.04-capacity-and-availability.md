## The number that lied

The public event page reads `availableTickets` from the event row and shows "12 left". A hold is created, then expires, then another hold is created. The number is updated in three different handlers; one forgets. The page now shows 12 when the real answer is 4.

A stored "available" number is a second source of truth. The primary facts are capacity, sold, and held. Availability is a calculation.

## The formula

```ts
export function availableQuantity(capacity: number, sold: number, held: number) {
  if (capacity < 0 || sold < 0 || held < 0) {
    throw new Error("Quantity cannot be negative.");
  }
  if (sold + held > capacity) {
    throw new Error("Inventory invariant violated.");
  }
  return capacity - sold - held;
}
```

The function is pure, so it is easy to test. The invariant is checked before the subtraction. If the data is already invalid, do not clamp it silently; log the violation and fix the write path.

In Week 1, `soldQuantity` and `heldQuantity` are zero because holds and orders do not exist yet. The page can still show capacity and "on sale". The formula is the contract that Module 4 will make real.

## The public projection

Do not return raw counters to the public. Return what the buyer needs:

```ts
function toPublicTicketType(ticketType: {
  id: string;
  name: string;
  description: string | null;
  priceCents: number;
  currency: string;
  maxPerOrder: number;
  capacity: number;
  soldQuantity: number;
  heldQuantity: number;
}) {
  const available = availableQuantity(
    ticketType.capacity,
    ticketType.soldQuantity,
    ticketType.heldQuantity
  );

  return {
    id: ticketType.id,
    name: ticketType.name,
    description: ticketType.description,
    priceCents: ticketType.priceCents,
    currency: ticketType.currency,
    maxPerOrder: ticketType.maxPerOrder,
    available,
    soldOut: available === 0,
  };
}
```

The public projection still exposes `available`, which is enough to render the page. It does not expose the counters or the organizer's internal data.

## Public event detail

```ts
publicEventRouter.get("/events/:slug", async (req, res, next) => {
  try {
    const event = await prisma.event.findFirst({
      where: { slug: req.params.slug, status: "PUBLISHED" },
      include: { ticketTypes: true },
    });

    if (!event) {
      return res.status(404).json({
        success: false,
        message: "Event not found.",
        code: "NOT_FOUND",
      });
    }

    res.json({
      success: true,
      data: {
        id: event.id,
        slug: event.slug,
        title: event.title,
        description: event.description,
        venueName: event.venueName,
        venueAddress: event.venueAddress,
        timezone: event.timezone,
        startsAt: event.startsAt,
        endsAt: event.endsAt,
        coverImageKey: event.coverImageKey,
        ticketTypes: event.ticketTypes.map(toPublicTicketType),
      },
    });
  } catch (error) {
    next(error);
  }
});
```

The `status: "PUBLISHED"` filter is part of the query. A direct URL to a draft returns `404`, not a rendered draft.

## The write path is the authority

The read path computes availability for display. The write path in Module 4 must decide whether a hold or order may claim capacity. It will use a conditional update or a row lock inside a transaction:

```sql
UPDATE ticket_types
SET held_quantity = held_quantity + $1
WHERE id = $2
  AND sold_quantity + held_quantity + $1 <= capacity;
```

If zero rows are updated, the claim failed. Do not read availability and then write in a separate step; that is the race.

## Verify

- `availableQuantity(10, 3, 2)` returns `5`.
- A negative quantity throws.
- `sold + held > capacity` throws.
- A draft event's public URL returns `404`.
- The public response does not include `soldQuantity` or `heldQuantity`.
- A sold-out tier has `soldOut: true` and `available: 0`.

## Key ideas

- Availability is `capacity - sold - held`.
- Expose a public projection, not raw counters.
- The read path can be approximate; the write path must be exact.
- Module 4 makes the counters move atomically.
